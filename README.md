✨ Robo A.I. Luna ✨
Welcome to Robo A.I. Luna, a fun and interactive web application designed for kids! This project features two main components: an AI chat assistant and an interactive roboeyes experience.

🚀 Features
Chat with A.I. Luna: Engage in friendly and cheerful conversations with Luna, an AI assistant designed to explain things simply and use fun examples.

Play with Roboeyes: Interact with animated roboeyes that can track your face (if camera access is granted) and display various expressions like happy, sad, angry, dizzy, love, sleepy, waking up, and crying.

🔗 Live Demo
You can access the live application here:
https://azmilazzo.github.io/kids/

🛠️ How to Use
Open the Main Page: Navigate to the live demo link above.

Choose Your Adventure:

Click "Chat with A.I. Luna" to start a conversation.

Click "Play with Roboeyes" to interact with the animated eyes.

🔒 Privacy & Permissions
Important Note for Users:

When you use certain features of this application (like the AI chat with speech input or the Roboeyes with face tracking), your browser may ask for permission to access your microphone and/or camera.

Microphone and Camera Access: This access is strictly for in-browser functionality. Your audio and video streams are processed directly within your web browser and are never recorded, stored, or sent to any external servers or third parties. Your privacy is our top priority.

API Key Storage: If you configure an API key for the AI chat feature, it is stored only in your local browser storage. It is not transmitted or stored on any server. Please keep your API key confidential.

👨‍💻 Development Setup (for Contributors)
To run this project locally:

Clone the repository:

git clone https://github.com/azmilazzo/kids.git

Navigate to the project directory:

cd kids

Open index.html: Simply open the index.html file in your web browser.

The project consists of three main HTML files:

index.html: The main landing page.

aichat.html: The AI chat application.

roboeyes.html: The interactive roboeyes application.
